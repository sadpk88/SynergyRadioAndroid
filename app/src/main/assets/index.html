Méthode 1 : Sans coder avec PWABuilder (La plus rapide — 5 min)

              
1. Hébergez ce fichier HTML et le fichier manifest.json sur votre hébergement web en HTTPS (ou GitHub Pages / Netlify gratuit).

              
2. Allez sur pwabuilder.com, entrez l'adresse de votre page et cliquez sur Package for stores → Android (Google Play).

              
3. Téléchargez le fichier .aab (Android App Bundle) signé et déposez-le dans votre Google Play Console.

            

            

              
Méthode 2 : Android Studio Natif avec Google AdMob (Recommandé pour AdMob)

              
1. Ouvrez Android Studio → New Project (Empty Activity) avec le package com.synergyradio.app.

              
2. Collez le code MainActivity.kt fourni dans l'onglet ci-dessus : il intègre déjà votre flux https://fire.doscast.com/8080/stream via Media3 ExoPlayer ainsi que la bannière adaptative AdMob non intrusive en bas d'écran.

              
3. Cliquez sur Build → Generate Signed Bundle / APK (.aab) pour publier sur le Play Store.
